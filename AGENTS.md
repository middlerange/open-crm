# Orbit agent notes

- Use the Vite+ `vp` CLI for installs, checks, builds, tests, formatting, linting, and package operations.
- Use `vp run <script>` for package scripts whose names overlap Vite+ commands.
- Keep outbound email and LinkedIn execution manual until the operating motion is validated. The app records work; it does not send outreach.
- Preserve company-level ownership and duplicate protections. One company has one accountable owner.
- Founder and manager roles can see team-wide reporting. ICs can only see their own execution data plus shared approved assets.
- Never place credentials in source control. Use environment variables and do not print secret values.
- Keep the product deployable as one Node application plus PostgreSQL.
